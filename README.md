# Bacılar Landing Page

Next.js ile hazırlanmış Türkçe landing page. Node.js 22 veya üzeri gerekir.

## Çalıştırma

npm ci
npm run dev

## Kontroller

npm run lint
npm run build

## Vercel

Add New → Project → fatmahazalguleryuz-rgb/bac-lar-landing reposunu Import et.
Framework: Next.js. Root Directory: . (repo kökü).
Build Command: npm run build. Install Command: npm ci.
Output Directory varsayılan kalsın. Deploy seç.
Sonraki main commitleri otomatik yayınlanır.

## App Store

Vercel ortam değişkenlerine NEXT_PUBLIC_APP_STORE_URL olarak gerçek App Store adresini ekle ve yeniden deploy et.
Adres verilmezse düğmeler iOS uygulaması yakında gösterir.
Yerelde .env.example dosyasını .env.local olarak kopyalayıp değeri doldur.

Sosyal medya ve hukuki sayfalar henüz Yakında durumundadır.
Uygulama önizlemeleri HTML/CSS konsept görselleridir.
